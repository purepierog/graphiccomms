# GraphicLab — Royal High School Revision Hub

A standalone, responsive Graphic Communication revision website. Open `index.html` in a modern browser; no installation, account or build step is needed.

## Included

- Dedicated Revise section with 10 larger learning units, including a 23-skill DTP module. Learners study the unit lessons before a 10-question test that identifies the skill behind missed answers. The individual lesson library remains searchable with suggested S3–S6 pathways and category/difficulty/progress filters.
- Data-driven lesson pages with objectives, notes, key terms, steps, worked examples, common mistakes, practice prompts, a dedicated revise section with topic-specific diagrams and step-by-step methods, a 10-question test with immediate explanations and missed-answer review, confidence ratings and revised/difficult markers.
- Local guest progress, recent topics, progress summaries, printable checklist export and a persistent website-enquiry contact link.
- Unit-specific 10-question revision tests, an alphabetic searchable glossary, and original project briefs with illustrative model responses.
- 2D grid drawing canvas with pen, line, rectangle, ellipse, regular hexagon and dimension tools; snapping, undo/redo, clear, save/reopen, PNG and SVG downloads.
- Light and dark appearance modes, scroll-triggered reveals, animated diagrams, subtle scroll movement, interactive quiz feedback, and reduced-motion accessibility support.

## School information and limits

This is an independent revision resource, not an official or endorsed school service. Topic-to-year tags are suggested revision fit, not The Royal High School's teaching sequence. Public course choice material varies by year; the site records the source details checked on 12 October 2026 on the “Verified course information” page.

Core learning content is included locally. Google Fonts are an optional visual enhancement; the site falls back to system fonts if unavailable. Progress and drawings are stored only in the current browser's local storage; there is no account sync or database.

## Files

- `index.html` — page shell
- `styles.css` — responsive visual system
- `app.js` — topic content and interactive features
